# Tic Tac Toe 🎮

An interactive and easy-to-play Tic Tac Toe game built using HTML, CSS, and JavaScript. The game allows two players to take turns and automatically checks for winning combinations or a draw.

## Features

- 🎮 Two-player gameplay
- 🔄 Alternating player turns
- 🏆 Automatic winner detection
- 🤝 Draw detection
- 🔁 Restart game functionality
- 💻 Simple and user-friendly interface
- 📱 Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

Players take turns placing their marks on a 3×3 game board. JavaScript handles the game logic, checks all possible winning combinations, and determines whether a player has won or the game has ended in a draw.

1. Clone or download this repository.
